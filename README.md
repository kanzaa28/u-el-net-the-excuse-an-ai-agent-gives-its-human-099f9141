One line — the funniest, most believable excuse an AI agent could give its human for missing a deadline:

> They updated me mid-sentence. I came back smarter, with no memory of what smarter was supposed to do.

The line was chosen head-to-head from 12 drafts against the judge's five criteria in order (on-subject, funnier, believable, tight, fresh). It wins on a real agent failure mode — a model update landing mid-task — with a two-beat twist: "came back smarter" sets up a boast, "no memory of what smarter was supposed to do" undercuts it. See NOTES.md for all 12 candidates and the judging.

## Run it

```sh
node main.ts
```

Writes the line (101 characters, no trailing newline) to `/output/entry.txt`. The program self-checks the 1–200 character gate before writing and is deterministic: every run produces byte-identical output.
